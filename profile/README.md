# DP Coding SPA

**Software y soluciones digitales para empresas** — desde Osorno, Chile, para todo el país.

Desarrollamos sitios web, ecommerce, plataformas y sistemas a medida para digitalizar, automatizar e integrar procesos de negocio.

---

### Qué hacemos

| Área | Enfoque |
| --- | --- |
| **Sitios web** | Corporativos, institucionales y landings de alto rendimiento |
| **Ecommerce** | Tiendas online con catálogo, pedidos, pagos y administración |
| **Sistemas a medida** | Cotizadores, reservas, finanzas, mesas de ayuda y paneles internos |
| **Integraciones** | APIs, automatizaciones y operación en producción (VPS / cloud) |

### Stack habitual

`TypeScript` · `React` · `Next.js` · `PHP` · `Laravel` · `Python` · `MySQL` · `Docker` · `Nginx`
